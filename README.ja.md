# Taffy

[English](README.md) | 日本語

macOS で、複数のブラウザやターミナル（Ghostty / Terminal.app）で開いているタブをまとめて検索し、選んだタブへすぐ切り替えるためのメニューバーアプリです。

ホットキー（デフォルトは `⇧⌘Space`）を押すと検索パネルが開き、起動中のブラウザすべてのタブがタイトルと URL で絞り込めます。`⇥`（Tab キー）でターミナルのタブの検索に切り替わり、Claude Code を実行中のタブを探せます。

## 機能

- 起動中の対応ブラウザ全部のタブを横断検索（タイトル、URL、ブラウザ名）
- スペース区切りで複数キーワードの AND 検索。部分一致に加えてあいまい一致（`gthb` → GitHub）にも対応。全角/半角や大文字/小文字は区別しません
- 選んだタブをアクティブにし、そのウィンドウを最前面に（最小化されていれば元に戻します）
- パネルからタブを閉じる
- 音声を再生中・カメラ / マイク / 画面共有を使用中のタブにアイコンを表示し、一覧の先頭に並べる（[後述](#音声やカメラを使っているタブ)）
- 前回取得したタブを先に表示し、各ブラウザの結果が届き次第更新します
- ブラウザとターミナルの検索を `⇥` で切り替え（[後述](#ターミナルのタブ)）。Claude Code を実行中のターミナルのタブには印を付けて先頭に並べます
- ログイン時に起動（メニューバーのメニューから設定）

## インストール

Homebrew の tap（[`yteraoka/homebrew-cask`](https://github.com/yteraoka/homebrew-cask)）で配布しています。

```sh
brew install --cask yteraoka/cask/taffy
```

- ビルド済みのユニバーサル版（Apple Silicon / Intel、macOS 13 以降）を GitHub Releases から `/Applications/Taffy.app` に入れます
- アプリは ad-hoc 署名で公証していないため、cask のインストール時に quarantine 属性を外しています

アンインストールは `brew uninstall --cask yteraoka/cask/taffy`（設定も消すなら `--zap`）です。

ソースからビルドする場合は [開発者向け情報](docs/development.md) を参照してください。

## キー操作

| キー | 動作 |
| --- | --- |
| `⇧⌘Space` | パネルを開く / 閉じる |
| `↑` `↓`（`⌃P` `⌃N`、`⌃K` `⌃J`） | 選択を移動 |
| `⌘↑` `⌘↓` | 先頭 / 末尾へ |
| `Page Up` `Page Down` | 8 件ずつ移動 |
| `↩` | 選択中のタブを開く |
| `⇥`（`⇧⇥`） | ブラウザとターミナルの検索を切り替え |
| `⌘1` / `⌘2` | ブラウザ / ターミナルの検索に切り替え |
| `⌘M` | ブラウザ: 音声 / カメラ / マイク / 画面共有を使っているタブだけを表示。ターミナル: Claude Code を実行中のタブだけを表示（もう一度押すと解除） |
| `⌘⌫` | 選択中のタブを閉じる（ブラウザのみ） |
| `esc` | パネルを閉じる |

日本語入力の変換中は `↩` や矢印キーは IME 側に渡します。クリックでも開けます。

パネル右上の「Browsers / Terminals」をクリックしても切り替えられます。最後に使った方を覚えていて、次にパネルを開いたときもそちらで開きます。

## ターミナルのタブ

ターミナルの検索では、Ghostty と Terminal.app のタブが一覧に出ます。2 行目には作業ディレクトリ（Ghostty）や tty と実行中のプロセス（Terminal.app）を表示します。

Claude Code を実行中のタブにはオレンジの ✦ が付き、検索語が空のときは先頭に並びます。`⌘M`、パネル下部の「N running Claude Code」、または検索欄の `@claude`（`@cl`、`@cc` でも可）で、それらのタブだけに絞り込めます。そのタブの 2 行目には Claude Code を起動したディレクトリを表示するので、プロジェクト名でも探せます。

ターミナルのタブを直接開くホットキーも設定できます（デフォルトはなし）。

```sh
defaults write com.github.yteraoka.taffy terminalHotkey "ctrl+shift+space"
```

### 制限

- ターミナルのタブは閉じられません（中で動いているプロセスが終了してしまうため）
- 分割（split）したタブでは、どれか 1 つのペインで Claude Code が動いていれば対象になります
- Ghostty ではタブのタイトルで Claude Code を判定しています（Claude Code は実行中のターミナルのタイトルを `✳ …` などに変えるため）。`CLAUDE_CODE_DISABLE_TERMINAL_TITLE` でタイトルの変更を止めている場合は判定できません
- Terminal.app は AppleScript でタブごとのタイトルを教えてくれないため、選択中のタブはウィンドウ名、それ以外はカスタムタイトルか実行中のプロセス名を表示します
- Ghostty の作業ディレクトリはシェルが最後に通知したもの（OSC 7）で、シェルの統合機能が無効だと空になります
- Ghostty 1.2 以前は AppleScript に対応していないため一覧に出ません

## 音声やカメラを使っているタブ

音声を再生しているタブや、カメラ・マイク・画面共有を使っているタブ（Web 会議など）には、一覧の右側にアイコンが付きます。

| アイコン | 状態 |
| --- | --- |
| 赤のビデオ | カメラを使用中 |
| オレンジのマイク | マイクを使用中 |
| 紫の画面 | 画面を共有中 |
| 青のスピーカー | 音声を再生中 |
| 灰色の消音スピーカー | ミュート中 |

- 検索語が空のときは、カメラ / マイク / 画面共有のタブ、音声再生中のタブ、ミュート中のタブの順で先頭に並びます
- パネル下部の「N with audio/camera」をクリックするか `⌘M` で、それらのタブだけに絞り込めます
- 検索欄に `@media`（すべて）、`@camera`、`@mic`、`@screen`、`@audio`、`@muted` と入れても絞り込めます。`@cam` のように前方一致でもよく、ほかの語と組み合わせられます（例: `@audio youtube`）

### 有効にする

ブラウザは AppleScript ではこの状態を教えてくれないため、タブバーをアクセシビリティ API で読んでいます。そのため「アクセシビリティ」の許可が必要です。

パネル下部の「Enable audio/camera indicators…」か、メニューバーの「Audio & Camera Indicators…」を選ぶと、システム設定のアクセシビリティの画面が開くので、Taffy をオンにしてください。許可しなくても、タブの検索と切り替えはこれまでどおり使えます。

アドホック署名のため、Homebrew でのアップグレードやビルドし直しのたびに macOS が別アプリとみなし、前の許可が効かなくなります。システム設定では Taffy がオンのまま表示されていても、オフ→オンでは直りません。許可しているのにアイコンが出なくなったときは、Taffy を終了し、一覧から Taffy を「−」で削除（または次のコマンドを実行）してから、Taffy を起動して許可し直してください。

```sh
tccutil reset Accessibility com.github.yteraoka.taffy
```

### Web 会議のタブ（推定）

Chromium 系のブラウザはタブに状態を 1 つしか出さず、Web 会議中は「音声を再生中」が優先されます。そのため Brave や最近の Chrome では、Google Meet のタブがカメラ / マイク使用中として読み取れません。

そこで Taffy は、次のことを macOS に問い合わせます（追加の権限は要りません。デバイスを開くわけではありません）。

- Mac のどこかでカメラが使われているか
- そのブラウザ自身が音声を出力しているか、マイクから録音しているか（macOS 14.2 以降。ブラウザのヘルパープロセスも含めて、アプリ単位で分かります）

使われているときは、音声を再生中（またはミュート中）の Web 会議サイトのタブに、カメラ / マイクのアイコンを付けます。対象は Google Meet、Zoom、Microsoft Teams、Webex、Whereby、Jitsi Meet、Amazon Chime です（`Sources/Taffy/CaptureInference.swift` の `meetingHosts`）。

アクセシビリティの許可がないなどでタブバーを読めないときも、ブラウザが音声を出力・録音していれば、そのブラウザの Web 会議サイトのタブにスピーカー / マイクのアイコンを付けます。Web 会議サイト以外のタブは、どのタブが音を出しているかまでは分からないため、アイコンは付きません。

推定なので、ほかのアプリ（Zoom アプリなど）がカメラを使っている間に Web 会議のタブが音声を出していると、誤ってカメラのアイコンが付きます。macOS 14.1 以前ではマイクも Mac 全体の状態で判定するため、ほかのアプリがマイクを使っているときや、マイクと音声出力を兼ねるデバイス（AirPods や USB ヘッドセットなど）で音声を再生しているだけのときにも、マイク使用中と判定されることがあります。

### 制限

- 英語と日本語のブラウザ表示で判定しています。ほかの言語では判定できないことがあります
- タブバーが見えていないウィンドウ（Safari でタブが 1 つだけのウィンドウなど）や、別の操作スペースにあるウィンドウのタブは判定できません
- Arc はタブがサイドバーにあるため、今のところ判定できません
- アイコンが出ないときは `defaults write com.github.yteraoka.taffy mediaDebug -bool true` を設定して Taffy を再起動すると、読み取ったタブの情報と、macOS から見たブラウザの音声出力 / 録音の状態（`trusted=0` ならアクセシビリティの許可が効いていません）が Console.app（`Taffy media` で検索）に出ます

## 権限について

初めてタブを取得するとき、ブラウザやターミナルごとに「“Taffy”から“Google Chrome”を制御しようとしています」というダイアログが出るので「許可」を選んでください。

拒否してしまった場合や、パネル下部に `not allowed to control this app` と表示される場合は「システム設定 > プライバシーとセキュリティ > オートメーション」で Taffy の該当アプリをオンにしてください。

アドホック署名のため、Homebrew でのアップグレードのたびに macOS が別アプリとみなし、許可を求められ直すことがあります。許可の状態がおかしくなったときは次のコマンドでリセットできます。

```sh
tccutil reset AppleEvents com.github.yteraoka.taffy
```

## ホットキーの変更

```sh
defaults write com.github.yteraoka.taffy hotkey "ctrl+option+t"
```

設定後に Taffy を再起動すると反映されます。修飾キーは `cmd` `shift` `option`（`opt` / `alt`）`ctrl` が使え、キーは英数字、`space`、`return`、`tab`、`f1`〜`f12`、記号（`,` `.` `/` `;` `'` `[` `]` `-` `=` `` ` ``）が指定できます。ほかのアプリと重なって登録できなかった場合は、メニューにショートカットが表示されません。

元に戻すには:

```sh
defaults delete com.github.yteraoka.taffy hotkey
```

## 既知の制限

- Chrome などで同じブラウザのウィンドウが複数あると、ウィンドウは前面に出てもキーボードフォーカスが前のウィンドウに残ることがあります（ブラウザ側の AppleScript 実装の挙動）
- Arc で別の Space にあるタブが一覧に出るかどうかは Arc の AppleScript 実装に依存します
